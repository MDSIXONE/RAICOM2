# 机器狗资料

本目录用于保存统一平台规格、上位机、摄像头、下位机和接口开发参考资料。

## 目录

| 目录 | 内容 |
| --- | --- |
| `compute/` | 上位机（树莓派 CM / 地平线 RDK X 系列）参考资料 |
| `camera/` | 摄像头参考资料 |
| `control/` | ESP32 下位机参考资料 |
| `course-resources/` | 课程课件与示例资源原始包 |
| `actual-hardware-observations.md` | 当前实机的网络、串口、IMU 和上位机识别观测 |
| `download-manifest.md` | 下载来源、文件用途、校验值和确认状态 |

## 重要说明

竞赛规则只明确了上位机与下位机的候选范围，未公开具体装机型号、相机型号、镜头参数、机械臂型号和完整通信接口。实际开发前应拍照记录实机标签，并向比赛技术支持确认型号和版本。

`private/` 用于本机敏感资料（如设备访问信息），不纳入版本控制。

# 项目黑话词典（project-lingo）

用户经常用口语化短句下达操作指令，这些"黑话"在具体项目中有精确的展开定义。
本 skill 是触发入口：**词条正文在 `docs/lingo.md`**，本文件只负责规则与高频索引。

## 首次使用

若 `docs/lingo.md` 不存在，按本文件末尾的「词条模板」创建该文件，并在「高频索引」
登记已有词条；告知用户词典已初始化。

## 使用规则

1. 用户指令命中词典条目 → 按该条目的「精确动作」执行，**先检查前置条件**，
   并遵守「不是」清单（防止执行成别的东西）。
2. 用户指令未命中词典 → **先向用户询问确认含义**，再执行；用户确认后，
   按「新增条目流程」沉淀新词条。
3. 执行指令涉及的权威命令细节以「权威来源」指向的文档为准，词条只做展开摘要。

| --- | --- | --- |

## 新增条目流程（维护机制）

- 触发时机：对话中 AI 不理解用户口语，或用户纠正了 AI 的误解。
- 步骤：AI 先询问确认 → 把条目写入 `docs/lingo.md`（按模板）→ 在本索引加一行
  → 回复中告知用户"已沉淀词条 xxx"。
- 条目必须包含：等价说法 / 含义 / 前置条件 / 精确动作 / 不是 / 权威来源。

## 词条模板

```markdown
## <黑话>

- **等价说法**：<用户可能说的其他说法>
- **含义**：<一句话精确含义>
- **前置条件**：<执行前必须满足的条件；无则写"无">
- **精确动作**：
  1. <步骤 1>
  2. <步骤 2>
- **不是**：<容易混淆的其他含义/对象，逐条列出>
- **权威来源**：<指向 docs 下权威文档的具体章节>
```

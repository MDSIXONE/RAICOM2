# AI 工作记录

此目录保存可跨对话复用的开发经验。不要删除历史记录，也不要虚构未发生的事件。

| 文档 | 用途 |
| --- | --- |
| `CHANGE_LOG.md` | 保存代码改动单元及其状态、验证和风险 |
| `MISTAKE_INDEX.md` | 犯错记录索引（主题索引 + 按日期索引，保持小体积） |
| `mistakes/YYYY-MM-DD.md` | 犯错记录正文，按日分文件（每天一个文件） |
| `FAILED_APPROACHES.md` | 保存已停止方案的原因与后续动作 |

`project-memory-records` 是这些文档所有读取和写入时机的唯一规则来源。

### PowerShell 使用反斜杠转义双引号导致 SSH/Python 命令截断

- **现象**：SSH 内嵌 Python 命令被截断为 `import`，远端产生 IndentationError；本地 Python 校验里的引号同样被截断，产生 SyntaxError。上传文件已存在，但第一条替换命令未执行；后续修正后完成替换与验证。
- **原因**：在 PowerShell 命令文本中使用 `\"` 转义双引号；PowerShell 不将反斜杠视为转义符，复杂命令被本地拆开解析。
- **修复**：远端脚本以 Base64 传输，通过单引号格式模板构造 SSH 命令；本地 Python 使用不含内嵌双引号的 BeautifulSoup 选择器校验。
- **预防**：区分 JSON 字符串转义与 PowerShell 命令转义；PowerShell 单引号字符串内使用两个单引号表达字面单引号，不使用反斜杠转义。执行每个原生命令后检查退出码。

### Playwright range fill 使用带尾零数值触发 Malformed value

- **现象**：网页测试以 `fill('0.60')` 填充 range 滑块时报告 Malformed value，后续截图因测试中断没有生成。
- **原因**：浏览器规范化 range 数值为 `0.6`，带多余尾零的测试字符串与原生控件规范化值不一致。
- **修复**：测试填充使用 `0.6` / `0.8`，随后检查 output 的两位小数显示和保存载荷的数值。
- **预防**：range 交互测试使用规范化数值字符串；显示格式单独验证，测试失败后不要直接读取尚未生成的截图。

### 墙控非零 VX/yaw 低于物理起动门槛导致减速区停滞

- **现象**：墙控仍 enabled、无错误，但航向指令 -8.1 或前进指令 1.x 时机器狗不动，终点条件不能满足。
- **原因**：只限制最大速度，没有保证低速/PID输出达到实机起动门槛；现场最大转向12本身也低于实测右转14/左转16。极小减速输出还可能在最终限幅前被 round 成0，掩盖未完成的运动需求。
- **修复**：实测 IMU/雷达后设置不可由网页降低的指令下限；控件、保存接口、最终发送三层约束，取整前限制非零指令，0仍是停车。最大速度参数也不得低于保守起动下限。
- **预防**：控制参数上限、下限与最终驱动链路一起验证；单位测试必须覆盖减速、微小增益、方向翻转及真正停车，不把“UDP发送成功”当成“已经实际运动”。

### 雷达扇区距离受偏航与测点切换影响，误判平移死区

- **现象**：短前进测试伴随约3.7°偏航，前距由约1.43m跳至1.19m；低档左横移时左侧距离反而增加。直接比较扇区近距会误认为前移23cm或横移方向错误。
- **原因**：前向近场机身回波被过滤后，有效点主要位于扇区边缘；姿态变化导致近距统计换到别的表面。随帧选择最近拟合平面也会在不同表面间跳变。
- **修复**：固定参考墙面，以支持点最多且法向受限的墙面拟合垂距，保持参考距离/法向窗口；静止前后多帧中位数与 MAD估计测量噪声。记录伴随偏航和提前停车，不把扇区变化直接当作纯平移。
- **预防**：物理死区标定必须区分传感器噪声、旋转、真实平移和可见表面变化；选定档位重复测量，并保存原始判据与数据。

### 雷达墙面连续性检查把遮挡缺口当成整面无效

- **现象**：前墙约0.78m、24个支持点，方向/残差合理，但0.67m回波缺口使前墙None，左墙流程停在waiting_wall_geometry。
- **原因**：以整条距离带的最大缺口淘汰全部支持点，没有将遮挡两侧各自有效片段分开拟合。
- **修复**：按缺口分段，逐片段校验点数/跨度/方向/残差；不跨缺口拼接短片段。原始现场回放与部署后新扫描均恢复前墙约0.81m。
- **预防**：同时覆盖有遮挡的有效墙和分散短片段；识别条件需在真实扫描上复核，不只使用完整平面合成点。

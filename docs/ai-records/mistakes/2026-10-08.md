### 巡线状态和参数使用重复 DOM ID lineLost

- **现象**：原网页“丢线帧数”状态和“丢线确认帧数”滑块都使用 `id="lineLost"`，`getElementById` 取到状态元素后，配置加载/收集会命中错误元素。
- **原因**：添加状态指标与参数时没有检查整个页面的 ID 唯一性，已有 UI 测试只检查 `wall` 前缀。
- **修复**：状态指标改为 `lineLostFrames`，参数维持 `lineLost`；唯一 ID 测试覆盖全部控件，浏览器验证状态帧数为 2 时配置仍保持 5 并正常保存。
- **预防**：状态指标与参数控件使用不同 ID；布局重组时核对全页 ID 唯一性和配置实际往返。驾驶快捷键也必须检查当前工作区和输入焦点，避免调参时发送运动指令。

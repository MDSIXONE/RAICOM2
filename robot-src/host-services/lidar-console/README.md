# RAICOM2 非 ROS 雷达避障与网页控制台

面向 `192.168.137.253` 的 XGO Mini3W_W。直接使用机器自带的 **YDLIDAR Tmini Plus** SDK 和已有 `oumax-xgo/manual_control_server.py`，不依赖 ROS。

## 功能

- `/dev/ttyUSB0` / 230400 读取 Tmini Plus，网页 10 Hz 实时雷达图。
- 自动模式保持前进 `VX`，根据左右/左前/右前障碍连续计算 `VY` 横移避障。
- 正前方进入危险距离时先停止前进，再选择较空的一侧横移；极近且四周拥堵时停止。
- 网页显示 VX/VY、五个障碍扇区、雷达状态、控制状态。
- 网页显示 **Estimated Path**：由已发送的 VX/VY 积分，仅用于观察控制轨迹，不是定位真值。
- 支持完全角度 mask 与“角度+近场距离”的自体回波过滤；后者可过滤机身/机械臂近场回波，同时保留同方向更远的真实障碍。
- 服务启动后默认 `idle`，不会自动驱动机器狗，必须在网页明确点击“启动自动横移避障”。
- 连续运动走机器端 UDP 控制通道；该通道自带约 0.35 s watchdog，网页服务或网络中断时会自动停车。
- 网页修改的参数保存到 `config.json`，下次启动继续使用。
- 网页“视觉巡线”复用旧项目 `follow_line.py` 的黑线 HSV 掩码、上下左右裁剪、线宽过滤、PID、丢线探测和线宽突变右转逻辑；网页可调整 HSV 六个上下限及全部巡线控制参数，参数保存到 `line_follow_config.json`。
- 巡线预览：`/line.mjpg` 为带框画面，`/line-mask.mjpg` 为黑线掩码画面。
- 网页“左墙定距直行”在启动时记录当前 IMU yaw，前进时用 VY 横移将左侧雷达距离维持在 0.30m 附近，同时用转向修正保持初始航向。
- 该模式共执行三段左墙直行：每段前方距离到达 0.30m 后停止前进，继续完成左距和航向对齐；条件连续满足后，前两段分别原地右转 90°，第三段结束时停车并自动退出。
- 每次右转以启动航向减去 90° / 180° 为 IMU 目标，使用现有航向增益与最大转向速度；转弯时 VX/VY 为 0，角度误差进入允许范围并连续确认后才进入下一段。确认只计新的传感器帧，转弯后等待新的雷达扫描。
- 右转最多执行 30 秒，超时或 IMU/雷达失联会中止整个流程并显式报错；网页显示当前段号、转向目标和动作。
- 左墙定距直行与手动、自动避障、视觉巡线互斥；IMU 或雷达数据中断时会停车并显式报错。
- 左墙工作区有三套完整的 13 项参数：“第一段与右转 · 公共参数”、“第二段 · 左墙直行独立参数”、“第三段 · 左墙直行独立参数”。第二段和第三段分别独立调节前进速度、左距目标、前停/减速距离、距离/航向容差、横移增益与限速、航向增益与限速、控制频率和完成确认帧数；横移方向校准全局共用。
- 第三段参数使用 `wall_final_*` 字段；滑动条调节后防抖实时保存到 `config.json`，第三段运行中从下一控制周期起生效。旧配置首次升级时，第三段按已有公共参数初始化；后续独立保存，不随公共参数修改而改变。

## 网页工作区

底盘速度下限已按 2026-10-13 实测锁定：前进指令至少 3；稳定右移至少 2.5、左移至少 8；右转至少 14、左转至少 16。网页共用横移参数采用下限 8，共用转向参数采用下限 16。数值是 SDK 指令刻度；左移 5/6 已有小位移，选择 8 是重复测试稳定运动的保守下限，未声称 8 是精确的物理死区边界。

控件范围、配置接口及最终 UDP 执行输出均限制非零速度。修改方向校准、减小 PID/航向增益或进入减速区，也不能发送低于对应方向下限的非零指令；0 保留停车含义。低于新下限的旧速度配置会显式记录升级并上调，距离目标和其他调参保留。原始标定与限制说明见 [实测记录](../../../docs/technical/motion-deadzone-2026-10-13.md)。

- **实时监控**：集中查看摄像头、雷达、定位路径和设备连接状态。
- **底盘操控**：手动方向控制、IMU 自稳、自动横移避障与底盘速度。
- **视觉巡线**：检测画面和 HSV 掩码紧邻参数；按 HSV、裁剪、PID、丢线探测和线宽突变分组，滑块仍实时保存。
- **左墙定距**：三段直行与两次 90° 右转的流程进度，独立启停、距离/航向反馈，以及终点、横移和航向三组参数。
- **机械臂**：实时关节角度；每个关节的输入与应用按钮放在一起。
- **雷达设置**：避障距离阈值、方向校准、显示半径和回波过滤。

顶部“立即停止”在所有工作区常驻。W/A/S/D 只在底盘操控工作区生效，编辑参数时不触发驾驶；退出该工作区会结束正在发送的手动运动指令。空格停止在非输入状态下生效。工作区支持 `#line`、`#wall` 等链接直达，手机端导航以网格呈现。

## 运行

机器狗部署目录建议 `/home/pi/oumax-lidar-console`：

```bash
cd /home/pi/oumax-lidar-console
./start.sh
```

然后浏览器打开：

```text
http://192.168.137.253:8088
```

`start.sh` 会检查 `127.0.0.1:8765` 的 XGO 手动控制服务；如果没运行，会使用 `/home/pi/RaspberryPi-CM5/xgovenv/bin/python` 启动它，确保 `xgolib` 可导入。

## 默认避障参数

- 巡航 VX: 12 cm/s
- 最大横移 VY: 9 cm/s
- 0.80 m 开始避障
- 0.34 m 停止前进并横向逃逸
- 0.22 m 紧急阈值
- 0.12 m 以内视为自体/雷达近场回波

首次使用请低速测试 A/D 横移方向。如果页面方向与真机相反，将网页里的 `VY 方向` 切换为反向后保存。

## 连续拍照

机器狗执行 `/home/pi/capture_photos.sh`；电脑可执行 `ssh pi@192.168.137.253 /home/pi/capture_photos.sh`。每次默认100张、以0.4秒定时取最新摄像头帧，保存到 `/home/pi/robot-photos`：第一次0.jpg–99.jpg，下一次100.jpg–199.jpg。每次运行扫描现有最大编号，从下一号继续，独占目录锁并以独占创建方式避免覆盖；中途退出后已保存照片保留，下次仍续号。

程序复用控制台 `/camera.mjpg` 的640×480 JPEG，不占用第二个摄像头实例。控制台必须在线，连接/帧错误会明确报错。每批额外保存 `batch-开始号-结束号.json`，记录编号、接收时间及实际定时取帧间隔；摄像头本身帧率限制实际曝光时间精度。可用 `--output 路径` 改保存目录；`--count`、`--interval` 默认100和0.4。
